# ST-089 — List community stores only after they pass the conformance suite

**Milestone:** M3 · **Epic:** m3-1-x · **Priority:** must · **Depends on:** ST-077

## Context

Sets the rule for listing community stores: the project lists a store such as MySQL or MongoDB only after it passes the conformance suite, and every listed store links to a green conformance run (NFR-59). REQ-36 puts community stores in M3.

Builds on the published conformance suite (TECH-105, ST-054) and on 1.0 (ST-077). Only ST-090 builds on it.

Lives in the documentation (NFR-28) and the repository's contribution process; no package changes. Where the list is published and what a submission must contain are not in the specs (open question 1).

## Acceptance criteria

### AC-1 · NFR-59 · must

> **Community store listing** — The project shall list a community store (MySQL, MongoDB or other) only after it passes the conformance suite.
>
> *Measure:* every listed store links to a green conformance run · *Verification:* inspection

- Inspection: the reviewer opens the list of community stores and checks that every entry links to a run of Bellhop.Storage.Conformance (TECH-105) against that store, and that the linked run is green. The check and the list as it stood are recorded in Notes.
- Given a store whose linked run is not green, or that links to no run, then it is not on the list.
- Given the list is empty, then the measure holds, and the documented way to propose a store asks for the link to a green run.
- Which suite version the run must use, and when a store leaves the list, are open question 2.

## Tests

Every test carries one `Trait("Req", "<id>")` for each item it verifies. No code test is required for NFR-59; a CI check that validates the list's links, if one is added, carries NFR-59.

- Inspection, recorded in Notes: NFR-59.

## Out of scope

- First-party MySQL or MongoDB stores: hosting REQ-8 (not shipped in v1).
- The conformance suite itself: ST-054 (TECH-105).
- Building or maintaining community stores: their authors; NFR-59 governs only the listing.

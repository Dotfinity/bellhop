# ST-083 — Test the Redis store in process with a Garnet fixture

**Milestone:** M3 · **Epic:** m3-1-x · **Priority:** may · **Depends on:** ST-082, ST-027

## Context

Adds an in-process Garnet server fixture to Bellhop.Testing, built on Garnet's NuGet package, so the Redis store, and applications that use it, can be tested without Docker (TECH-75). REQ-36 puts the Garnet fixture in M3.

Builds on ST-027 (Bellhop.Testing, TECH-102) and ST-082 (the Redis store proven on Garnet, TECH-74). Only ST-090 builds on it. The CI matrix keeps Garnet in Docker (TECH-87, ST-084); the fixture is an addition, not a replacement.

Lives in Bellhop.Testing (TECH-75, TECH-102). The fixture's public type and method names, and whether Garnet becomes a dependency of every Bellhop.Testing user, are not in the specs (open questions 1 and 2).

## Acceptance criteria

### AC-1 · TECH-75 · may

> **In-process Garnet fixture** — Bellhop.Testing shall use Garnet's NuGet package to offer an in-process server fixture so the Redis store can be tested without Docker.

- Given a test project that references Bellhop.Testing and Bellhop.Redis on a CI agent where Docker is not available, when a test starts the fixture and points the Redis store at it, then the node starts and the store conformance suite (TECH-105) passes against the fixture.
- Given the fixture, then its server has Lua enabled, so a node using it passes REQ-502's startup check.
- Given two fixtures in one process, then each is its own server, and nothing written through one is visible through the other (NFR-53).
- Inspection: Bellhop.Testing references Garnet's NuGet package at a version that TECH-74 allows (2.1 or later); the package works on both target frameworks (TECH-1) and passes the vulnerability scan (NFR-44). The reviewer records the package, its version and its licence in Notes.

## Out of scope

- Garnet support in the Redis store itself: ST-082 (TECH-74).
- Docker-based Redis testing in CI: ST-084 (TECH-87).
- Fixtures for other servers or stores: no item asks for them; the Testcontainers sample for PostgreSQL and SQL Server is TECH-106 (ST-073).
